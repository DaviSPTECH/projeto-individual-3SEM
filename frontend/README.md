# 🚇 Transporte Urbano — Frontend 

> Interface desenvolvida em **React** para cadastro, visualização e remoção de rotas.

## Funcionalidades

* Cadastro de rotas
* Listagem de rotas
* Remoção de rotas
* Estados de carregamento, sucesso e erro
* Integração com a API REST

---

## Campos

* Origem
* Destino
* Estação inicial
* Estação final
* Duração
* Quantidade de baldeações

---

## Tecnologias

* React
* JavaScript
* JSX
* CSS Modules
* Fetch API

---

## Execução

```bash
npm install
npm run dev
```

Frontend: `http://localhost:5173`

O backend deve estar executando em `http://localhost:8080`.
